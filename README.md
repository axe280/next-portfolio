# Personal Portfolio

This is my personal portfolio website showcasing my CV, projects, skills, and professional experience.

---

## ✨ Overview

The website presents my background as a developer, including:

- 📄 CV / Resume
- 💼 Personal and professional projects
- 🧠 Technical and soft skills
- 📫 Contact information

The goal is to provide a simple, clear, and accessible overview of my work and capabilities.

---

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript
